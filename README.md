Process

## How a project runs

Every project moves through the same five steps, so you always know what comes next.

1. 1

   ### Discover

   We listen first: goals, audience, constraints and what success looks like in numbers.
2. 2

   ### Design

   Wireframes and visual design you can click through before any code is written.
3. 3

   ### Build

   Clean, tested code on tools your team can maintain after handover.
4. 4

   ### Launch

   Deployment, redirects and analytics, with a checklist so launch day is uneventful.
5. 5

   ### Improve

   We read the data, fix what is slow or confusing, and ship updates in small steps.
